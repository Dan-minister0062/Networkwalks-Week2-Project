Networkwalks Week 2 – Penetration Testing Report
Footprinting & Network Scanning Phases
Program: Networkwalks Cybersecurity Internship (Batch B082)
Modules Completed: W2-PM1, W2-PM5, W2-PM-FINAL 
📋 Overview
This repository contains the Week 2 project for the Networkwalks Cybersecurity Internship. The project covers:
- Footprinting of `networkwalks.com` using multiple Kali Linux tools (WHOIS, WhatWeb, NSLookup, Curl, Wafw00f, DNSRecon)
- Network Scanning of the local lab network using Zenmap (Ping, Quick, Regular, Intense scans)
- Final Report documenting methodology, findings, risk analysis, and recommendations
📄 Full Report
The complete report is available here: [Week2_Report.pdf](./Week2_Report.pdf)
📸 Screenshots
All screenshots are organized in the [Screenshots](./Screenshots/) folder.
🔧 Tools Used
| Tool | Purpose |
|------|---------|
| WHOIS | Domain registration lookup |
| WhatWeb | CMS and technology fingerprinting |
| NSLookup | DNS record resolution |
| Curl | HTTP header inspection |
| Wafw00f | WAF detection |
| DNSRecon | DNS enumeration |
| Zenmap | Network host discovery and port scanning |
⚠️ Disclaimer
All testing was conducted within the authorized scope defined by Networkwalks. No exploitation or disruptive testing was performed. This repository is for educational purposes only.
